# Django-проект Skystore

## Описание

Django-приложение для интернет-магазина Skystore с каталогом товаров, админкой и системой управления данными. Проект включает полную настройку PostgreSQL, модели товаров и категорий, фикстуры и кастомные команды управления.

## 🚀 Основные возможности

- **Каталог товаров** с категориями и продуктами
- **Страница товара** с подробной информацией
- **Главная страница** с отображением всех товаров
- **Базовые шаблоны** для единообразного дизайна
- **Админ-панель Django** с настройками отображения
- **PostgreSQL** база данных
- **Система медиафайлов** для изображений товаров
- **Фикстуры** для тестовых данных
- **Кастомные команды** для управления данными
- **Переменные окружения** для безопасности

## 🛠 Установка и настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com/moldique/starter_project
cd starter_project
```

### 2. Установка зависимостей
```bash
poetry install
```

### 3. Настройка PostgreSQL
```bash
# Убедитесь, что PostgreSQL запущен
# Создайте базу данных django_catalog
```

### 4. Настройка переменных окружения
Создайте файл `.env` в корне проекта:
```env
# Database settings
DB_NAME=django_catalog
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432

# Django settings
SECRET_KEY=your-secret-key-here
DEBUG=True
```

### 5. Применение миграций
```bash
poetry run python manage.py migrate
```

### 6. Создание суперпользователя
```bash
poetry run python manage.py createsuperuser
```

### 7. Загрузка тестовых данных
```bash
# Загрузка фикстур
poetry run python manage.py loaddata catalog/fixtures/catalog_data.json

# Или создание данных через кастомную команду
poetry run python manage.py add_test_products
```

### 8. Запуск сервера
```bash
poetry run python manage.py runserver
```

## 🔧 Основные команды

### Управление данными
```bash
# Создание тестовых данных (очищает базу)
poetry run python manage.py add_test_products

# Создание с параметрами
poetry run python manage.py add_test_products --count 15 --categories 3

# Загрузка фикстур
poetry run python manage.py loaddata catalog/fixtures/catalog_data.json

# Очистка базы данных
poetry run python manage.py flush --noinput
```

### Разработка
```bash
# Запуск сервера
poetry run python manage.py runserver

# Django shell
poetry run python manage.py shell

# Проверка системы
poetry run python manage.py check

# Создание миграций
poetry run python manage.py makemigrations

# Применение миграций
poetry run python manage.py migrate
```

### Качество кода
```bash
# Проверка кода
poetry run flake8 .

# Форматирование
poetry run black .

# Проверка типов
poetry run mypy .

# Тесты
poetry run pytest
```

## 📊 Модели данных

### Category (Категория)
- `name` - название категории
- `description` - описание категории
- `created_at` - дата создания
- `updated_at` - дата обновления

### Product (Продукт)
- `name` - название продукта
- `description` - описание продукта
- `image` - изображение продукта
- `category` - связь с категорией (ForeignKey)
- `price` - цена продукта
- `is_available` - доступность продукта
- `created_at` - дата создания
- `updated_at` - дата обновления
