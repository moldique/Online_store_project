# Кастомные Django команды

Этот каталог содержит кастомные Django management команды для приложения catalog.

## Команды

### `add_test_products`

Команда для создания тестовых данных в базе данных каталога.

**Описание:**
- Удаляет все существующие данные из базы данных
- Создает новые категории и продукты
- Выводит подробную статистику

**Использование:**

```bash
# Создать 10 продуктов и 5 категорий (по умолчанию)
poetry run python manage.py add_test_products

# Создать 15 продуктов и 3 категории
poetry run python manage.py add_test_products --count 15 --categories 3

# Создать 5 продуктов и 2 категории
poetry run python manage.py add_test_products --count 5 --categories 2
```

**Параметры:**
- `--count COUNT` - количество продуктов для создания (по умолчанию 10)
- `--categories CATEGORIES` - количество категорий для создания (по умолчанию 5)

**Что делает команда:**

1. **Очистка данных:**
   - Удаляет все существующие продукты
   - Удаляет все существующие категории
   - Выводит количество удаленных записей

2. **Создание категорий:**
   - Электроника
   - Одежда
   - Книги
   - Спорт
   - Дом и сад

3. **Создание продуктов:**
   - iPhone 15 Pro - $999.99
   - Samsung Galaxy S24 - $899.99
   - MacBook Air M3 - $1299.99
   - iPad Pro - $799.99
   - AirPods Pro - $249.99
   - Джинсы Levis 501 - $89.99
   - Куртка North Face - $199.99
   - Футболка Nike - $29.99
   - Кроссовки Adidas - $129.99
   - Python для начинающих - $29.99

4. **Статистика:**
   - Количество созданных категорий и продуктов
   - Распределение продуктов по категориям
   - Топ-3 самых дорогих продукта

**Безопасность:**
- Команда использует транзакции для обеспечения целостности данных
- При ошибке все изменения откатываются
- Все операции выполняются атомарно

**Рекомендации:**
- Используйте команду для инициализации тестовых данных
- Не запускайте в продакшене без предварительной проверки
- Создавайте резервные копии перед запуском команды
